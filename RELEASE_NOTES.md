# Pixel System UI Cache Shortcut v0.3.0

## 日本語

- PixelのSystem UIストレージ設定画面をワンタップで表示。
- 「キャッシュを削除」は手動で操作します。自動削除機能なし。
- **広告なし・追加で要求するAndroid権限なし・通信処理なし**。
- **安全性は各自でソースコードを確認し、必要に応じAIでレビューしてください。AIの評価は安全性を保証しません。**
- 動作確認：Pixel 10 Pro XL / Android 17。その他の端末・バージョンは未検証。

## English

- One-tap System UI storage settings shortcut for Google Pixel.
- Manually tap **Clear cache**; the app does not delete cache itself.
- **No ads, no requested Android permissions, and no network activity.**
- **Review the open-source code yourself, optionally with AI. AI review does not guarantee security.**
- Tested: Pixel 10 Pro XL / Android 17. Other devices and versions are untested.
